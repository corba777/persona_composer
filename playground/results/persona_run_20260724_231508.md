### Часть 1. Что за хуйня этот ваш FCC и его катализаторы?

**FCC (Fluid Catalytic Cracking)**, или по-нашему **флюид-каталитический крекинг** — это, без пизды, сердце любого современного НПЗ. 

Суть процесса: мы берем тяжелую, вонючую и дешевую хурму (вакуумный газойль, мазут) и хуярим её при температуре под 500–540 °C, чтобы разорвать длинные углеводородные цепочки. На выходе получаем высокооктановый бензин, легкий газойль и кучу пропилен-бутиленовой фракции (сырье для нефтехимии).

Но без катализатора эта реакция шла бы медленно, хуево и давала бы кучу бесполезного кокса и газа. 

#### Из чего состоит эта пиздюлина (катализатор)?
Это микросферический порошок (размером с пыльцу, 60-80 микрон), который ведет себя в потоке газа как кипящая жидкость (отсюда и *Fluid*). Анатомия у него хитрая:
1. **Активный компонент (Зеолит / Zeolite):** Обычно ультрастабильный цеолит Y (USY) или REY (с редкоземельными металлами). Это такая кристаллическая решетка с порами, куда пролезают только молекулы определенного размера. Именно там происходит основная магия крекинга.
2. **Активная матрица (Alumina/SiO2):** Помогает предварительно «развалить» совсем гигантские молекулы, которые в поры цеолита тупо не пролезают.
3. **Связующее и наполнитель (Clay/Kaolin):** Глина для прочности, чтоб этот порошок не стерся в пыль за два круга по реактору.
4. **Добавки (Additives):** Спец-присадки для улавливания серы (DeSOx), снижения выбросов азота (DeNOx) или увеличения выхода пропилена (ZSM-5).

### Часть 2. Как лабы выбирают правильный катализатор?

Подбор катализатора — это вечная ебля и компромисс. Не бывает «просто лучшего» катализатора, каждый раз его затачивают под конкретный завод и конкретную задачу.

Лаборатории смотрят на три кучи факторов:

1. **Какое сырье заходит (Feedstock properties):**
   * Плотность, фракционный состав.
   * Содержание коксогенных структур (микрококс по Конрадсону).
   * **Яды (Metals):** Никель и Ванадий. Это главные враги. Никель запускает реакцию дегидрирования (начинает лететь водород, компрессор на заводе захлебывается и наступает пиздец). Ванадий тупо разрушает структуру цеолита при высокой температуре. Если металлов до хуя, нужен катализатор с «ловушками» (metal traps).

2. **Ограничения установки (Unit constraints):**
   * Какая температура в регенераторе? (Если слишком жарко, катализатор быстро сдохнет от деактивации).
   * Какая производительность компрессора жирного газа и воздуходувки регенератора?

3. **Что мы хотим получить на выходе (Yield targets):**
   * Нужен максимум бензина?
   * Или завод хочет заработать на пропилене для полимеров?
   * Или надо снизить выход кокса, потому что регенератор перегревается?

**Как тестируют в лабе:**
Сначала катализатор искусственно «старят» паром (чтобы симулировать его работу на реальной установке в течение пары недель), а потом гоняют на микроактивноопределяющих установках (**MAT** — Micro Activity Test) или пилотных циркулирующих установках (**ACE** — Advanced Catalytic Evaluation). На выходе получают простыню данных: конверсия, выход бензина, легкого цикла, кокса, газов.

* **Таргеты (Outputs / Результаты эксперимента):**
  * Конверсия сырья (%).
  * Выход целевых фракций (бензин, пропилен, бутан-бутиленовая фракция).
  * Выход нежелательных продуктов (кокс, водород, сухой газ).

#### Шаг 3.2. Как поставить задачу для ML?
Тут есть два пути: простой и рабочий.

* **Путь А (Классификация — «Хуйня вопрос, но негибко»):**
  Сделать мультиклассовую классификацию, где таргет — это ID катализатора, который показал лучший результат в эксперименте. 
  *Минус:* Модель не поймет физику процесса. Если появится новый катализатор, которого не было в обучении, модель обосрётся.

* **Путь Б (Регрессия + Ранжирование — «По уму, без пизды»):**
  Мы строим **суррогатную модель процесса**. 
  1. Обучаем регрессионную модель (например, XGBoost, LightGBM или CatBoost), которая по входным параметрам (Сырье + Параметры процесса + Свойства катализатора) предсказывает ключевые показатели эффективности (например, `Выход_Бензина`, `Выход_Кокса`, `Конверсия`).
  2. Когда приходит запрос на новый эксперимент (задано сырье и режим работы):
     * Мы берем из нашей базы данных профили всех доступных катализаторов (их физико-химические свойства).
     * Для каждого катализатора подставляем его свойства в модель вместе с параметрами нового эксперимента.
     * Модель предсказывает выходы продуктов для каждого кандидата.
     * Мы ранжируем результаты по какому-то бизнес-критерию (например: максимизировать бензин при условии, что кокс < 5%) и выдаем **ТОП-3 лучших ID катализаторов**.

#### Шаг 3.3. Набрасываем пайплайн на Python

Вот примерный скелет кода, как это захуячить быстро и без лишней ебли:

```python
import pandas as pd
import numpy as np
from lightgbm import LGBMRegressor

# 1. Загружаем наши эксперименты
# Предположим, там колонки: feed_density, feed_nickel, feed_vanadium, temp, 
# cat_zeolite_content, cat_surface_area, yield_gasoline, yield_coke
df = pd.read_csv('fcc_experiments.csv')

# Определяем фичи сырья и режима (X1) и свойства катализатора (X2)
features_feed_and_process = ['feed_density', 'feed_nickel', 'feed_vanadium', 'temp']
features_catalyst = ['cat_zeolite_content', 'cat_surface_area']
all_features = features_feed_and_process + features_catalyst

# Таргеты, которые нам важны для оценки
targets = ['yield_gasoline', 'yield_coke']

# 2. Обучаем модели под каждый таргет
models = {}
for target in targets:
    model = LGBMRegressor(n_estimators=100, random_state=42)
    model.fit(df[all_features], df[target])
    models[target] = model

# 3. Функция подбора ТОП-3 катализаторов под новое сырье
# catalog_df — это справочник всех доступных катализаторов и их свойств
def get_top_3_catalysts(new_feed_properties, catalog_df):
    results = []
    
    for idx, cat in catalog_df.iterrows():
        # Собираем вектор фич для теста конкретного катализатора
        input_data = {**new_feed_properties, **cat.to_dict()}
        input_df = pd.DataFrame([input_data])[all_features]
        
        # Предсказываем результаты
        pred_gasoline = models['yield_gasoline'].predict(input_df)[0]
        pred_coke = models['yield_coke'].predict(input_df)[0]
        
        # Считаем какую-то скоринг-функцию (бизнес-метрику)
        # Например: хотим много бензина, но штрафуем за высокий кокс
        score = pred_gasoline - (pred_coke * 2.0) 
        
        results.append({
            'catalyst_id': cat['catalyst_id'],
            'predicted_gasoline': pred_gasoline,
            'predicted_coke': pred_coke,
            'score': score
        })
        
    # Сортируем по оценке сверху вниз и забираем тройку лучших
    ranking_df = pd.DataFrame(results).sort_values(by='score', ascending=False)
    return ranking_df.head(3)
```

### Что может пойти по пизде (Важные нюансы):
1. **Экстраполяция:** Если ты обучишь модель на легком сырье, а потом засунешь туда тяжелый гудрон с кучей никеля — модель выдаст красивую, но абсолютно нереальную хуйню. Следи за границами применимости данных.
2. **Мультиколлинеарность свойств катализаторов:** Свойства катализаторов часто сильно связаны между собой (например, площадь поверхности и объем пор). Деревья решений (XGBoost) с этим справляются нормально, но линейные модели тут сразу сдохнут.
3. **Физический смысл:** Иногда модель может решить, что «чем больше никеля в сырье, тем больше бензина» просто потому, что в обучающей выборке на тяжелом сырье использовали супер-дорогие катализаторы. Добавляй регуляризацию или используй монотонные ограничения в моделях (monotonic constraints), чтобы физика процесса не шла по пизде.

Here's a brief overview of how chemical labs in the oil and gas sector pick the right Fluid Catalytic Cracking (FCC) catalysts, what an FCC catalyst is, and a structured approach to building a machine learning model to recommend the top 3 catalysts for a given experiment.

---

### What is an FCC Catalyst?

**Fluid Catalytic Cracking (FCC)** is one of the most important conversion processes used in oil refineries. It converts heavy, high-boiling hydrocarbon fractions of petroleum crude oil into more valuable gasoline, olefinic gases, and other products. 

An **FCC catalyst** is a fine, sand-like powder (typically with an average particle size of about 70 microns) that behaves like a fluid when aerated. It consists of four major components:
1. **Zeolite:** The primary active ingredient (usually synthetic Y-zeolite). It provides the crystalline structure and acid sites where selective cracking occurs.
2. **Active Matrix:** Alumina-based components that pre-crack large molecules that cannot fit into the zeolite pores.
3. **Binder:** Silica or alumina that holds the catalyst components together, giving it physical integrity.
4. **Filler:** Typically clay (kaolin), which provides density and mechanical strength to resist attrition (wearing down into fine dust).

---

### How Labs Choose the Right FCC Catalyst

Selecting the right catalyst is a complex optimization problem. Refineries use laboratory testing (such as Micro Activity Testing (MAT) or Advanced Catalytic Evaluation (ACE) units) to evaluate catalysts based on:
* **Feedstock Quality:** Heavy feeds with high levels of metals (like Nickel and Vanadium) require catalysts with metal traps to prevent catalyst deactivation and unwanted hydrogen production.
* **Operating Constraints:** Heat balance, regenerator temperature limits, and air blower capacities of the specific refinery unit.
* **Product Yield Targets:** Whether the refinery wants to maximize gasoline, LPG, propylene, or minimize coke and light cycle oil (LCO).

---

### Building the Machine Learning Model

To build a model that recommends the **top 3 catalysts** for a specific experiment, we can treat this as a **predictive modeling and ranking problem**. 

#### Step 1: Understand the Data Structure (The CSV File)
Your CSV likely contains three types of columns:
1. **Feedstock Properties (Inputs):** API gravity, sulfur content, nitrogen content, metal content (Ni, V, Fe), aniline point, etc.
2. **Operating Conditions (Inputs):** Reaction temperature, Catalyst-to-Oil (C/O) ratio, space velocity.
3. **Catalyst Properties (Inputs):** Zeolite surface area, matrix surface area, rare earth content, unit cell size, metal trap presence.
4. **Performance Metrics (Targets/Outputs):** Conversion rate, gasoline yield, coke yield, LPG yield, hydrogen yield.

#### Step 2: Modeling Strategy
Instead of predicting the catalyst directly (which fails if you introduce a new catalyst to the market), you should build a **surrogate model of the FCC process**:

1. **Train Regressor Models:** Train machine learning models (e.g., CatBoost, LightGBM, or Random Forest) to predict key performance outputs (like `gasoline_yield` and `coke_yield`) based on the combination of *Feedstock Properties + Operating Conditions + Catalyst Properties*.
2. **Define a Scoring Function:** Create a business-driven utility function. For example:
   $$\text{Score} = \text{Predicted Gasoline Yield} - (w \times \text{Predicted Coke Yield})$$
   *(where $w$ is a penalty weight for producing too much unwanted coke).*
3. **Recommend Top 3:** When a chemist inputs a new feedstock and set of operating conditions:
   * Map this input against the properties of all available catalysts in your database.
   * Run the trained model to predict the performance of each catalyst candidate.
   * Calculate the Score for each candidate.
   * Rank them and return the top 3 catalysts with the highest scores.
